# 誘惑を遠ざける設定（スクリーンタイムとオートメーション）

しおりの「5分だけ始める」は、始める瞬間の綱引きに勝つための仕組みです。
ここでは iPhone の機能を使って、綱引きの相手（SNS・漫画）そのものを遠ざけます。どれも iPhone 側で1回設定するだけです。

全部やらなくて大丈夫です。おすすめは **1 → 3** の順です。

操作の名前は iOS のバージョンで少し違うことがあります。近い名前を選んでください。迷ったら、その画面のスクリーンショットを Claude に送ってください。

---

## 1. SNS・漫画アプリに「1日の時間の上限」を付ける

1. **設定アプリ** →「**スクリーンタイム**」→「**App 使用時間の制限**」
2. 「**制限を追加**」
3. 「**SNS**」の丸にチェック（漫画アプリは「エンターテインメント」の中、または下の検索から個別に選ぶ）→「次へ」
4. 時間を決める（例：**30分**）。曜日ごとに変えたいときは「曜日別に設定」
5. 「**使用制限終了時にブロック**」をオンにして「追加」

上限に来ると画面がふさがります。「制限を無視」で延ばせますが、ひと手間挟まるだけで流れにくくなります。

## 2. 夜に「休止時間」を入れる（寝る前に明日を組んだあと用）

1. **設定アプリ** →「**スクリーンタイム**」→「**休止時間**」
2. 「**スケジュール**」をオン → 例：**23:30〜6:00**
3. 「**常に許可**」に、電話・メッセージなど必要なものだけを入れる

## 3. SNS を開いたら、しおり側へ引き戻す（オートメーション）

「SNS を開いた瞬間」に、しおりの合図を出します。綱引きの瞬間に、もう1つの選択肢を目の前に出すための工夫です。

1. **ショートカットアプリ** → 下の「**オートメーション**」→ 右上の「**＋**」（または「新規オートメーション」）
2. 「**App**」を選ぶ
3. 「**App を選択**」で、Instagram・X・漫画アプリなどを選ぶ →「完了」
4. 「**開いている**」にチェック（「閉じている」は外す）
5. 「**すぐに実行**」を選ぶ →「次へ」
6. 「**新規の空のオートメーション**」→ アクションを1つ足す。次のどちらかがおすすめです
   - **やわらかい形：** 「**通知を表示**」→ 本文「しおりの次の行き先は？ 5分だけ始めてもいい」
   - **強めの形：** 「**集中モードを設定**」→「しおり」を「オン」（集中モード「しおり」で SNS の通知も止まります）
7. 「完了」

※ ホーム画面のしおりを直接開くアクション（「App を開く」の一覧にしおりが出るか）は、iOS のバージョンによって違うため確かめられていません。一覧にしおりが出れば、6. の代わりにそれを選ぶのがいちばん強い形です。

## 4. 合わなかったら

どれも、同じ画面からオフにしたり消したりできます。きつすぎると感じたら、時間の上限を延ばすか、3. を「やわらかい形」に戻してください。
