# ショートカットの試し方（「5分だけ始める」用）

**やりたいこと：** しおりの「始める」ボタンから、iPhone の「ショートカット」アプリを動かせるか確かめます。
動かせれば、スマホを見なくても5分後に Apple Watch が知らせてくれる仕組みが作れます。

**今の形（2026-11-08）：** しおりで「5分だけ始める」を押すと、ショートカット「しおり5分」が集中モードをオンにし、予定の長さ（その場の5分は60分）たつと自動でオフにします。5分後の知らせは、しおりがサーバーから通知で送ります（README「9. 5分の知らせ」）。

（ステップ1「しおりから呼べるか」は確認済みのため、手順は省きました）

---

## ステップ2：集中モードをオンにする

5分後の知らせは、ショートカットではなく **しおりが通知で送る** 形に変えました（2026-11-08。README「9. 5分の知らせ」）。
ショートカット「しおり5分」の仕事は、**集中モード「しおり」をオンにすることだけ**です。

### 2-1. 集中モード「しおり」を作る（済んでいれば飛ばす）

1. iPhone の **設定アプリ** →「**集中モード**」→ 右上の「**＋**」→「**カスタム**」
2. 名前に **しおり** と入力 → アイコンを選んで「**次へ**」
3. 「通知を許可」の「**App**」→「**追加**」で **しおり** を選ぶ（5分の知らせが止まらないように）
   - 仕事の連絡に使うアプリもここで追加してかまいません

### 2-2. 「しおり5分」を作り直す（時刻が来たら自動でオフにする）

しおりは「何分後に切るか」を数字（例：60）でショートカットに渡します。ショートカットは「今から○分後」を計算し、その時刻まで集中モードをオンにします。

できあがりは **2行** です。

| 順 | 行の見た目（できあがり） | 役目 |
|---|---|---|
| 1 | 現在の日付 に **ショートカットの入力** **分** を 追加 | 切る時刻を計算する |
| 2 | しおり を **時刻** まで オン に変更（時刻＝調整済みの日付） | その時刻まで集中モードをオン |

**① 今の行を消す**

ショートカットアプリで「しおり5分」を開き、今ある行（「しおり を オフ時 まで オン に変更」など）を、右の ✕ で全部消します。

**② 1行目：切る時刻を計算する**

1. 下の検索欄に **日付を調整** と入力 →「**日付を調整**」をタップ
2. 「現在の日付 に **0** **秒** を 追加」という行ができる
3. 青い「**0**」をタップ → キーボードの上に並ぶ候補から「**ショートカットの入力**」を選ぶ
   - 候補が出ないとき：キーボードの上の「変数を選択」→「ショートカットの入力」
4. 青い「**秒**」をタップ →「**分**」を選ぶ
5. 「現在の日付 に ショートカットの入力 分 を 追加」になれば OK

**③ 2行目：その時刻まで集中モードをオン**

1. 検索欄に **集中** と入力 →「**集中モードを設定**」をタップ（1行目の下に入る）
2. 行の青い文字を、次のとおりに変える
   - 集中モードの名前 →「**しおり**」
   - 「オフ」→「**オン**」
   - 「オフ時」（期間）→「**時刻**」
3. 「時刻」を選ぶと、新しく青い欄（「時刻」など）が出る → タップ → 候補から「**調整済みの日付**」を選ぶ
4. 「しおり を 調整済みの日付 まで オン に変更」のようになれば OK
5. 右上の「完了」

**うまく作れたかの確かめ方**

しおり → 設定 →「始め方」→「**ショートカットを試す（5分で自動オフ）**」
→ 集中モード「しおり」がオンになり、**5分後に自動でオフ**になれば成功です。

### 2-3. しおりで使えるようにする

1. しおり →「設定」→「**始め方**」→「**ショートカットを試す（5分で自動オフ）**」を押す → 集中モード「しおり」がオンになり、5分後に自動でオフになれば成功
2. 同じところの「**「5分だけ始める」で集中モードをオンにする**」にチェックを入れる（この端末だけの設定です）

## うまくいかないとき

- **「ショートカットが見つかりません」と出る：** 名前が違います。「しおり5分」に、空白なしで直してください。
- **画面の言葉が手順と違う・どこを押すか分からない：** その画面のスクリーンショットを Claude に送ってください。
- **アクションの名前が見つからない：** iOS のバージョンで名前が少し違うことがあります。近い言葉で検索するか、そのまま Claude に聞いてください。
