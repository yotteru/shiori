# ショートカットの作り方（「5分だけ始める」用・実機テスト）

「5分だけ始める」で、しおりから iPhone のショートカットを呼び、集中モードと5分後の通知を任せます。
まだ試験段階です。設定タブの「テスト：ショートカットを呼ぶ」で、呼べるかを確かめます。

操作の名前は iOS のバージョンで少し違うことがあります。近い名前のものを選んでください。

## 0. 集中モード「しおり」を作る

1. 設定アプリ → 集中モード → 右上の「＋」→ カスタム → 名前「しおり」
2. 通知を許可する人・アプリ：仕事の連絡に使うアプリ、**リマインダー**（5分後の通知に使うので必須）
3. 通知を止めたいアプリ（SNS・漫画など）は許可しない
4. 必要なら「ホーム画面」で SNS・漫画のページを隠す
5. Apple Watch 側も同じ集中モードになるよう、Watch アプリ → 一般 → 集中モード →「iPhoneを反映」をオン

## 1. しおりテスト（呼べるかの確認だけ）

ショートカットアプリ → 「＋」→ 名前「しおりテスト」

- 「通知を表示」：本文「しおりから呼べました」

## 2. しおり5分（始めるとき）

名前「しおり5分」。しおりから行き先の名前が文字で渡されます。

1. 右上の「ⓘ」→ 入力を受け取る：テキスト（なければ省略して大丈夫）
2. 「集中モードを設定」：「しおり」を**オン**、期間は「オフにするまで」
3. 「日付」：現在の日付
4. 「日付を調整」：上の日付に **5分** を加える
5. 「新規リマインダーを追加」（または「リマインダーを追加」）
   - タイトル：「5分たちました。続けても、やめてもOK」
   - 通知：4 の日付
   - リスト：新しく「しおり」というリストを作って選ぶと、ほかのリマインダーと混ざりません

## 3. しおりおわり（終わるとき）

名前「しおりおわり」

- 「集中モードを設定」：「しおり」を**オフ**

## テストの順番（設定タブ → テスト：ショートカットを呼ぶ）

| ボタン | 成功の目安 |
|---|---|
| 1. 呼べるか | 「しおりから呼べました」の通知が出る |
| 2. 戻ってくるか | 動いたあと、ホーム画面のしおりに戻る（Safari が開いたら失敗） |
| 3. 始める | 集中モード「しおり」がオンになる。スマホをロックして5分待ち、iPhone と Apple Watch に通知が来る |
| 4. おわる | 集中モードがオフに戻る |

結果（どれが成功・失敗したか、確認の画面が出たか）を Claude に伝えてください。呼べなかった場合は、サーバーから送る通知（Web プッシュ）に切り替えます。
