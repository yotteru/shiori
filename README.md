# しおり

寝る前に「明日のルート」を組み、朝は「最初の一手」から始め、終わったら「済」をつける自己管理アプリ（v0）。

- 実装指示書：[docs/CLAUDE_CODE_INSTRUCTIONS.md](docs/CLAUDE_CODE_INSTRUCTIONS.md)
- 公開URL（予定）：https://yotteru.github.io/shiori/

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm test        # 自動テスト（Vitest）
npm run build   # 本番ビルド
```

利用者が手で行う設定（LINE・Supabase・GitHub Pages）の手順は、通知まで実装した段階でここに追記します。
